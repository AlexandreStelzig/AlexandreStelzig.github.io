Goal Tracker

An Android application that keeps track of daily and weekly goals set by the user. While goals remain unaccomplished, the app sends reminders. By tracking everyday progress, it keeps users productive and motivated.

View the source code on GitHub. Interested in an APK? Contact me.

Media

Main Features

  • Daily and weekly goal tracking with calendar navigation
  • Filter goals by category with persistent state
  • Customizable categories with unique colors
  • Goal and rule management with multiple counter types
  • Statistics for daily/weekly goals over date ranges
  • Customizable notification reminders
  • Automatic backup, export, and import via CSV
  • 8+ settings for personalization
