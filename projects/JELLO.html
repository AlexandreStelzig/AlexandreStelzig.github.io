uOttawa Japanese Club (JELLO)

A website and registration software built for the University of Ottawa Japanese Club. The website showcases club information and includes a contact form that sends messages directly to the club's email. The registration software streamlines club fair sign-ups by replacing pen-and-paper with an exportable digital system.

Visit the website at jello-aelj.github.io.

Main Features

  • Club website with about, news, and registration sections
  • Bilingual support (English/French)
  • Responsive design
  • Registration software for club fair sign-ups
  • Export names, emails, and language levels for easy import
