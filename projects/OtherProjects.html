Randomizer App

Having a hard time choosing between 2 or more things? The Randomizer app lets you create lists with weighted items that can be randomized. Each item has an associated weight that changes the odds of it being picked.

Source code on GitHub.

Video Game Store App

A fictional Android shopping application created for the Analysis and Design of User Interfaces course at the University of Ottawa. Features a full e-commerce flow with product browsing, cart, checkout, and account management.

Source code on GitHub.

Line Tracer Robot

A line-tracing robot built using Arduino during an Introduction to Robot Programming class in South Korea. Uses 4 light sensors for automatic line following and steering. Successfully finished the track in 34 seconds.
