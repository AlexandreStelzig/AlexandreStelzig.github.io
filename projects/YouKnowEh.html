You Know Eh? (2019)

A flashcard application for learning new languages through repetitive memorization. Built when I started learning Korean and wanted a better vocabulary tool with all the features I needed.

View the source code on GitHub. Interested in an APK? Contact me.

Media

Main Features

  • Review cards in random or chronological order, both directions
  • Card management with search, sort, import/export (CSV/ZIP)
  • Deck management with reordering and batch operations
  • 3 quiz types: Reading, Writing, and Multiple Choice
  • Quiz history with pass/fail stats and completion time
  • Statistics with date range filtering across decks
  • Multiple profiles with unique cards, decks, and settings
  • Automatic backup system with export/import
